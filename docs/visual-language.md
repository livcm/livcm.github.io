# Aneko 的奇想手记 · 视觉语言规范

本规范与网站共用一套组件语言。打开 [可视化样板](https://livcm.github.io/style-guide/) 可同时对照浅色、深色的配色和真实组件；本地预览对应路径为 `/style-guide/`。

## 1. 品牌与文案

- 网站名：**Aneko 的奇想手记**。
- 副标题：**记一点日常，写一点奇想。喵～**
- 来源：[GitHub 主页](https://github.com/livcm) 的昵称「Aneko奇幻菌喵🐾」及简介「A cute catgirl with twintail, nyan❤️~」。Aneko 提供个人识别，「奇想」呼应奇幻菌，「手记」说明写作与记录的定位。
- 默认作者显示名为 Aneko；GitHub 账号保持 livcm。文章指定作者时优先使用文章作者。
- 猫系气质通过品牌旁一枚线条爪印和副标题中的「喵」表达；正文、导航与帮助文案使用自然中文。
- 首页浏览器标题仅为网站名，其他页面采用「页面标题｜Aneko 的奇想手记」。首页标题可按自然语义分行，导航中的站名完整显示。

## 2. 参考图与视觉提取

参考：`2024_06_LANDSCAPE_PINK.heic`。原图属于视觉素材，未作为指令来源；不把原始 HEIC 作为网页背景或运行依赖。

| 画面元素 | 代表取样 | 视觉印象 | 界面转译 |
| --- | --- | --- | --- |
| 大面积天空 | `#F4E8E8` | 安静、温暖、呼吸感 | 偏暖的近白页面，充足留白 |
| 半圆日轮 | `#FADFE4` | 柔光、轻盈、温和 | 首页一处低对比度日轮 |
| 粉色沙丘 | `#FDC7D4` | 柔软、连贯 | 小面积粉色曲线与渐变 |
| 紫色沙丘 | `#D0BDEB` | 平静、纵深 | 层叠曲线中的紫色底层 |
| 前景浅紫 | `#C6BDF1` | 轻微冷暖变化 | 渐变与层次参考 |

取样来自解码后的 sRGB 图像。原图存在连续渐变，色值表示代表位置，而非唯一颜色。深色主题和文字色是为可用性补充的设计色，不属于原图直接取样。

关键词：**克制、柔和、层叠、留白、清晰**。景观只集中在首页引导区，文章正文使用纯色底面。用曲线建立气氛，用排版建立秩序。

## 4. 排版、布局与间距

- 字体：系统无衬线，优先使用系统 UI 字体，并回退到 PingFang SC、Hiragino Sans GB、Microsoft YaHei；代码使用 SFMono-Regular、Consolas 等宽字体。不加载外部字体。
- 正文 18px / 1.8；普通界面与摘要 16px；辅助信息和标签 14px。中文标题不用过细字重。
- 首页标题：桌面最大 60px，小屏 40px。页面标题 36–48px，文章标题 30–42px，正文二级标题 24–28px。长标题允许自然换行，不截断。
- 页面最大宽度 1120px；文章阅读区最大 44rem。桌面边距 48px，960px 以下边距 32px，640px 以下边距 20px。
- 在 960px 以下，个人资料与规范双主题对照改为单列；640px 以下，文章日期移到标题上方、联系方式变为单列、导航分两行。
- 首页景观在宽屏与介绍并排；640px 以下放到介绍下方，作为全宽的横向景观条，保持正常文档流。高度限制在 144–192px，按比例裁切，避免覆盖文案或漂浮在按钮旁。
- 间距尺度为 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px；段落间距 24px、主要章节间距 48–64px。
- 面板圆角 16px，控件圆角 8px，标签圆角 6px。面板使用细边线与轻阴影；文章列表通过留白和分隔线组织。

## 5. 组件与交互

- **导航**：首页、文章；当前栏目用文字颜色和短下划线表达。文章详情归入文章栏目。页脚保留源码、反馈与许可入口。
- **按钮与链接**：主要按钮使用交互色底面，次要按钮使用可辨识边框。主要控件至少 44px 高，正文链接有下划线；文章标题与联系入口在悬停时补充下划线。
- **焦点**：交互元素使用 3px 交互色外轮廓与 4px 间隔。键盘用户可通过首个「跳至正文」链接进入主要内容。
- **文章列表**：日期、已有分类、完整标题、100 字符以内的摘要。首页最多三篇，存档展示全部；没有文章时提供自然的空状态。
- **文章详情**：日期、作者、已有分类与标签；表格、代码只在自己的区域滚动。表格保留结构和表头，滚动代码示例可使用键盘聚焦。
- **个人信息**：联系方式集中管理于 `_data/profile.yml`，保留 X、Instagram 和邮箱的当前更新；游戏账号使用原生 `details` 折叠，支持无 JavaScript 操作。
- **主题**：跟随系统为首次默认，可手动选择浅色或深色；以 `aneko-theme` 存储偏好。首次绘制前设置 `data-theme`，手动选择优先于系统偏好，选择系统模式后响应系统变化。存储不可用时切换仍在当前页面生效；关闭 JavaScript 后由 CSS 跟随系统，隐藏无法工作的主题控件。
- **时钟**：首页次要信息区显示访客本地时间，每秒更新；页面进入后台时暂停。无重复的读屏播报，无 JavaScript 时隐藏时钟。
- **动效**：180ms 颜色、背景和边框过渡，箭头只有小幅移动；遵循 `prefers-reduced-motion`，关闭平滑滚动和动画。
- **装饰**：SVG 曲线和爪印标记为 `aria-hidden`，不参与焦点顺序；不承担内容或交互信息。

## 6. 页面与兼容边界

首页顺序为站名与副标题 → 最新文章 → 全部文章入口 → 联系与游戏账号 → 仓库入口和时钟。GitHub 数据以真实链接提供，不保留远程统计徽章。

保留既有文章永久链接和 `/posts.html`、`/404.html`。所有站内导航和资源通过 `relative_url` 兼容 `baseurl`；GitHub Pages 的 `/posts` 无扩展名入口仍对应文章页。新增 `/style-guide/`，主导航仅保留首页与文章。

规范文档不参与站点发布。扫雷页 `mine.html`、原文章内容和 favicon 保持原样。本次重构不依赖远程模板、外部字体、图标服务或前端框架；配置中的 `theme: null` 显式关闭 GitHub Pages 的默认主题回退。

## 7. 验收清单

- `bundle exec jekyll build` 成功，生成首页、文章列表、文章详情、404 和样板页。
- 320 / 768 / 1440px、200% 缩放和两种主题均能阅读；没有整页横向溢出。
- 主题覆盖系统偏好、重新加载持久化、系统变化、存储异常及禁用 JavaScript 均正常。
- 键盘焦点、展开区域、跳至正文和减少动态效果正常。
- 核对标题、联系方式、游戏账号、许可证、站内链接以及原文章路径；验证扫雷文件无变化。
- 检查正文和次要文字的对比度，参考 [WCAG 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 与 [焦点可见](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html)。
- 对实际页面与样板页进行浅色、深色和移动端截图复核。
